# Demonstração E2a

`pacote-sintetico-completo.zip` contém nove atividades dos oito tipos e duas apresentações. É válido para a aula/slots sintéticos semeados por `tests/fixtures/lesson-package-db.mjs`, descritos em `identidade-sintetica.json`. `kit-work-sintetico.zip` contém identidades, contratos e instruções correspondentes.

Em qualquer outra aula, usar **Exportar kit para o Work** e **Baixar pacote sintético** no painel: os UUIDs precisam corresponder àquele ambiente. Não adaptar UUIDs manualmente nem importar esse exemplo em produção. Links Drive são fictícios e não comprovam acesso a materiais reais.

Gerar novamente: `npm.cmd run example:lesson-package`. Validar/ensaiar o fluxo: `npm.cmd run test:lesson-package` e `npm.cmd run test:lesson-package:browser`. Nada disso aplica migrations ou importa conteúdo em produção.
